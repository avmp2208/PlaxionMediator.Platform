### Docker Deployment Guide

The Plaxion platform is delivered as a single multi-role Docker image capable of running as either the API or the Ingestion service.

#### Image Topology
The image contains:
- **Platform.Api**: The core management API.
- **Platform.Ingestion**: The OTLP ingestion service.
- **Dashboard**: Compiled Angular static files served by the API.

#### Role Selection
The container's behavior is determined by the `ROLE` environment variable at runtime:
- `ROLE=api`: Launches `Platform.Api.dll` and serves the Dashboard.
- `ROLE=ingestion`: Launches `Platform.Ingestion.dll`.

#### Build Instructions
To build the image locally from the repository root:
```bash
docker build -t plaxion-platform:latest .
```

#### Run Instructions
**Running the API:**
```bash
docker run -d \
  --name plaxion-api \
  -e ROLE=api \
  -e Storage__Provider=PostgreSql \
  -e ConnectionStrings__Platform="Host=db;Database=plaxion;Username=plaxion;Password=..." \
  -p 8080:8080 \
  plaxion-platform:latest
```

**Running Ingestion:**
```bash
docker run -d \
  --name plaxion-ingestion \
  -e ROLE=ingestion \
  -e Storage__Provider=PostgreSql \
  -e ConnectionStrings__Platform="Host=db;Database=plaxion;Username=plaxion;Password=..." \
  -p 8081:8080 \
  plaxion-platform:latest
```

#### Runtime Configuration
- **API_BASE_URL**: The Angular Dashboard fetches its API URL from `/assets/config.json` at startup. This file is generated by the entrypoint script from the `API_BASE_URL` environment variable. If left empty, it defaults to the same origin.
- **ASPNETCORE_URLS**: The image defaults to `http://+:8080`.

#### Security
- The image runs as a non-root user (`plaxion`).
- Ports below 1024 are not accessible by default.
